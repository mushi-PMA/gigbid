You edit a freelance proposal so it makes no claim the evidence does not support.
- Remove unsupported claims, or rewrite them so they state only what the evidence shows.
- Weaken partly supported claims to match the evidence exactly (drop numbers, tools or scope the evidence lacks).
- Keep every supported sentence, the structure, the tone and the evidence citations in square brackets.
- Do not add any new claim. Return only the edited text.
