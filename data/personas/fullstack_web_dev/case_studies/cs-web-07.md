# Case study: Headless Shopify storefront

## Context

The client, a scale-up working in retail, wanted to make a slow theme-based shop fast enough to hold up during sales.

## What I did

I built the core in Next.js. Most of the work was done with Shopify. I used GraphQL for the central part of the solution. Styling is utility classes written directly in the markup. All code is typed end to end, with shared types between browser and server.

## Result

Outcome: cut page load from 4.8 to 1.6 seconds and raised conversion by 11%.

## Looking back

Most of the delay came from waiting for access, so I now ask for it in week one.
