# Case study: Learning management system

## Context

The client, a mid-size company working in edtech, wanted to host courses, quizzes and certificates for 5,000 students of a training company.

## What I did

- Everything starts with a single compose command on any machine.
- Hot lookups are served from an in-memory key-value store with expiry.
- I picked Vue.js because it kept the code short and testable.
- Most of the work was done with MongoDB.
- I used Express.js for the central part of the solution.

## Result

After launch: supported 5,000 active students on one small server.

## Looking back

I kept a short decision log, which saved a long meeting when priorities changed.
