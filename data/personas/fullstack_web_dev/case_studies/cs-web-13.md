# Headless CMS migration

## Context

In 2023 a mid-size company in media asked me to move a 12-year-old news site off a heavy theme without losing search ranking.

## What I did

- The team already knew GraphQL, so I used it.
- All code is typed end to end, with shared types between browser and server.
- I built the core in WordPress.
- I used Next.js for the central part of the solution.

## Result

What changed: kept organic traffic flat through the move and halved load time.

## Looking back

A small first release with real users taught us more than the planning did.
