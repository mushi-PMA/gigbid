# Case study: Niche job board

## Context

A startup in the hr tech sector came to me in 2023. They needed to run a paid job board for nurses with filters, alerts and employer accounts.

## What I did

- I used Django for the central part of the solution.
- PostgreSQL was the main tool here.
- A JSON API that both web and mobile clients call, with documented endpoints.
- Most of the work was done with React.
- Storage is S3 and compute is EC2 behind a load balancer.

## Result

Result: reached 40 paying employers in four months.

## Looking back

I kept a short decision log, which saved a long meeting when priorities changed.
