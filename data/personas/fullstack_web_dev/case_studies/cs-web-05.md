# Property listing site with map search

## Context

A small business in the real estate sector came to me in 2023. They needed to show homes on a map and let people filter by price, size and commute time.

## What I did

A JSON API that both web and mobile clients call, with documented endpoints. I picked Django because it kept the code short and testable. Layouts adapt from phone to wide desktop; small screens came first. I picked PostgreSQL because it kept the code short and testable. I used React for the central part of the solution.

## Result

Result: doubled enquiries from mobile visitors.

## Looking back

Most of the delay came from waiting for access, so I now ask for it in week one.
