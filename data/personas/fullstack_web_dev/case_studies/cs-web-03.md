# Case study: Logistics admin dashboard

## Context

A mid-size company in the logistics sector came to me in 2023. They needed to give dispatchers one screen for orders, drivers and delays instead of four spreadsheets.

## What I did

I picked Express.js because it kept the code short and testable. Everything starts with a single compose command on any machine. I used MongoDB for the central part of the solution. One screen of live tables and charts for the operations team. React did most of the heavy lifting.

## Result

After launch: cut dispatcher handling time per order by 30%.

## Looking back

Weekly demos kept the client close to the work and removed surprises.
