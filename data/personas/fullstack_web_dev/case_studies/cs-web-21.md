# GraphQL gateway

## Context

A scale-up in the fintech sector came to me in 2024. They needed to put one clean API in front of five older services that mobile and web both call.

## What I did

- I built the core in GraphQL.
- Most of the work was done with Node.js.
- Everything starts with a single compose command on any machine.
- A JSON API that both web and mobile clients call, with documented endpoints.
- The team already knew TypeScript, so I used it.

## Result

Outcome: cut mobile requests per screen from nine to two.

## Looking back

Weekly demos kept the client close to the work and removed surprises.
