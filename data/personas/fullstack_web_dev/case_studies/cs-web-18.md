# A donation website for a nonprofit in nonprofit

## Context

In 2023 a nonprofit in nonprofit asked me to take one-off and monthly donations with receipts and a clean thank-you flow.

## What I did

I picked React because it kept the code short and testable. Node.js did most of the heavy lifting. I picked Stripe because it kept the code short and testable. It works comfortably on small screens. Storage is S3 and compute is EC2 behind a load balancer.

## Result

Outcome: raised monthly donors by 28% after launch.

Handover notes and a recorded walkthrough made the last week calm.
