# A multi-tenant SaaS foundation for a startup in saas

## Context

The client, a startup working in saas, wanted to give a founder a base with organisations, roles and billing so the team can focus on the product.

## What I did

The team already knew Next.js, so I used it. I picked PostgreSQL because it kept the code short and testable. A pipeline checks and deploys each commit. The team already knew TypeScript, so I used it. Deployments use a pinned build recipe so library versions never drift.

## Result

After launch: saved the team roughly three months of groundwork.

## Looking back

Handover notes and a recorded walkthrough made the last week calm.
