# Case study: Invoicing SaaS

## Context

The client, a startup working in fintech, wanted to help freelancers create invoices, send reminders and take card payments.

## What I did

Next.js was the main tool here. The team already knew Node.js, so I used it. Card payments go through a hosted payment provider, and webhooks confirm every charge. All code is typed end to end, with shared types between browser and server. PostgreSQL was the main tool here.

## Result

After launch: got the first 300 paying users within five months.

## Looking back

I kept a short decision log, which saved a long meeting when priorities changed.
