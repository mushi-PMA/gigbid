# Subscription cohort analysis

## Context

In 2024 a startup in saas asked me to show the founders how long each signup month keeps paying and why the curve flattens.

## What I did

Python did most of the heavy lifting. A shared model holds the definitions once, so every report agrees. A central analytics store sits apart from the live application database. SQL was the main tool here. The team already knew Looker Studio, so I used it.

## Result

What changed: found an onboarding step that explained a 12 point retention gap.
