# Case study: Checkout A/B test analysis

## Context

The client, a scale-up working in e-commerce, wanted to tell the product team whether a new checkout page truly converts better or only looks better.

## What I did

- I picked SQL because it kept the code short and testable.
- Most of the work was done with Python.
- New versions ran against the old one on a random half of traffic before full rollout.
- I used Statistics for the central part of the solution.
- Managers see trend charts instead of tables.

## Result

Result: prevented a rollout that would have cost about 3% of orders.

## Looking back

Handover notes and a recorded walkthrough made the last week calm.
