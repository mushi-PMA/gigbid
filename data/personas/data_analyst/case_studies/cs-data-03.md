# Case study: Customer segmentation

## Context

Brief (2024, retail): group two million customers into a handful of segments marketing can act on.

## What I did

- Duplicates were removed, formats fixed and missing values handled before any analysis.
- Effects were checked with confidence intervals and significance tests.
- I picked Python because it kept the code short and testable.
- I picked Pandas because it kept the code short and testable.
- I used Tableau for the central part of the solution.

## Result

What changed: lifted email campaign revenue per send by 24%.

## Looking back

Weekly demos kept the client close to the work and removed surprises.
