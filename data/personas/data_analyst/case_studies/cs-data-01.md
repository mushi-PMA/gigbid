# Retail sales dashboard

## Context

The client, a mid-size company working in retail, wanted to show regional managers sales against target by store, product and week in one place.

## What I did

SQL did most of the heavy lifting. A shared model holds the definitions once, so every report agrees. I picked Microsoft Excel because it kept the code short and testable. Microsoft Power BI was the main tool here. A governed reporting layer serves the whole business with agreed definitions.

## Result

After launch: replaced six weekly spreadsheets and cut report prep from two days to two hours.

## Looking back

I would agree the definition of success with the client earlier next time.
