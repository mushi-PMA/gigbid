# Product recommendations

## Context

The client, a scale-up working in e-commerce, wanted to show shoppers products they are likely to buy next on the product and cart pages.

## What I did

- I used Python for the central part of the solution.
- The team already knew PyTorch, so I used it.
- Recent results are cached in memory so repeat requests return in milliseconds.
- New versions ran against the old one on a random half of traffic before full rollout.
- Recommendation Systems was the main tool here.

## Result

Outcome: lifted click-through on recommendations by 17%.

## Looking back

I would agree the definition of success with the client earlier next time.
