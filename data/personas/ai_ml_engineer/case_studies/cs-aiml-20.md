# A visual search feature for a scale-up in media

## Context

The client, a scale-up working in media, wanted to find archive photos that look like a photo an editor uploads.

## What I did

- Everything starts with a single compose command on any machine.
- I used Vector Databases for the central part of the solution.
- Most of the work was done with Computer Vision.
- Typed Python endpoints validate each request and publish interactive docs for free.
- PyTorch was the main tool here.

## Result

What changed: editors found a usable photo on the first page 78% of the time.

## Looking back

Weekly demos kept the client close to the work and removed surprises.
