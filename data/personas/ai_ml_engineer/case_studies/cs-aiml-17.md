# A voice appointment assistant for a mid-size company in healthcare

## Context

A mid-size company in the healthcare sector came to me in 2025. They needed to let patients book and move appointments by phone without waiting for a receptionist.

## What I did

Speech Recognition was the main tool here. Most of the work was done with Python. System messages were iterated against a fixed set of questions. Event-driven functions handle each call, so there is no server to look after. OpenAI API was the main tool here.

## Result

After launch: handled 63% of booking calls end to end.

## Looking back

I kept a short decision log, which saved a long meeting when priorities changed.
